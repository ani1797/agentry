# Itinerary template

Use this structure when writing `docs/travel/<trip-name>-itinerary.md`.

```markdown
# <Destination> — <Date range>

## Trip summary
- Travelers: <count>
- Budget: <amount>
- Flights: <shortlisted option(s) with price/duration>

## Day 1 — <date>
- Morning: ...
- Afternoon: ...
- Evening: ...
- Lodging: ...

## Day 2 — <date>
...

## Notes
- Open questions / things to confirm with the traveler.
```

Keep each day to 3-5 concrete activities; leave buffer time on arrival/departure days.
