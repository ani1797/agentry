# Edit

Use this workflow to improve an existing draft without changing its intended meaning.

Review for:

- audience fit and fulfilled purpose
- clear structure, flow, and headings
- precise, concise language
- consistent voice and terminology
- factual support, attribution, and uncertainty
- accessibility, including descriptive link text and readable lists

Return the revised draft and a short list of material factual gaps or editorial decisions. Do not silently rewrite verified technical meaning.
